# Mia Pet House

## Sobre o projeto

A Mia Pet House é uma plataforma web desenvolvida para apresentar produtos e serviços de um petshop. O projeto foi desenvolvido como parte da Fase 1 da disciplina de Fundamentos de Sistemas Web.

## Funcionalidades

O sistema permite a navegação entre as páginas de início, produtos e serviços.

Na página de produtos são apresentados produtos divididos nas seguintes categorias:

* Acessórios;
* Rações não perecíveis;
* Higiene e limpeza.

Cada produto possui imagem, descrição e valor.

Na página de serviços são apresentados:

* Banho;
* Tosa;
* Banho + Tosa.

Todos os serviços possuem descrição e valor. Também é apresentada a opção de tele-busca, com acréscimo de R$ 15,00 ao serviço escolhido.

O sistema também possui informações de contato do estabelecimento no rodapé das páginas.

## Estrutura do projeto

* `index.html` - Página inicial da Mia Pet House.
* `produtos.html` - Página destinada à apresentação dos produtos.
* `servicos.html` - Página destinada à apresentação dos serviços.
* `imagens/` - Pasta contendo a logo e as imagens utilizadas no sistema.

## Tecnologias utilizadas

* HTML5
* Visual Studio Code

## Navegação

O menu localizado no cabeçalho permite acessar as páginas principais do sistema.

O link **Contato** direciona o usuário para o rodapé da página, onde estão disponíveis as informações de contato da Mia Pet House.
