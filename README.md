# Mia Pet House

Projeto desenvolvido para a disciplina de Fundamentos de Sistemas Web.

O Mia Pet House é um sistema web de pet shop que apresenta produtos, serviços e permite o cadastro do cliente e do pet, além do agendamento dos serviços de banho e tosa.

## Funcionalidades

- Página inicial com apresentação do pet shop.
- Menu de navegação responsivo.
- Carrossel de produtos em destaque.
- Catálogo de produtos dividido em categorias.
- Página de serviços de banho e tosa.
- Cadastro de dados do cliente.
- Cadastro de dados do pet.
- Escolha entre os serviços de banho ou tosa.
- Escolha entre tele-busca ou entrega do pet no local.
- Seleção de data e horário para o agendamento.
- Cálculo do valor do serviço de acordo com as opções escolhidas.
- Mensagem de confirmação do agendamento utilizando JavaScript.
- Exibição da data e hora atuais com atualização automática.
- Recursos de acessibilidade.

## Recursos de acessibilidade

O projeto utiliza recursos para melhorar a acessibilidade, como:

- textos alternativos (`alt`) nas imagens;
- associação entre `label` e campos dos formulários;
- atributos ARIA em elementos de navegação;
- identificação dos controles do carrossel para leitores de tela;
- destaque visual de elementos durante a navegação pelo teclado.

## Melhorias realizadas na Fase 2

Em relação à primeira fase do projeto, foram realizadas as seguintes melhorias:

- aplicação de CSS próprio para personalização da interface;
- utilização do Bootstrap para responsividade e organização dos elementos;
- implementação de menu de navegação responsivo;
- inclusão de carrossel de imagens na página inicial;
- reorganização dos produtos utilizando cards;
- reformulação da página de serviços;
- criação do formulário de cadastro do cliente e do pet;
- implementação do agendamento dos serviços de banho e tosa;
- inclusão das opções de tele-busca e entrega do pet no estabelecimento;
- utilização de calendário para escolha de data e horário;
- utilização de JavaScript para interação com o formulário;
- cálculo automático do valor do serviço;
- mensagem dinâmica de confirmação do agendamento;
- implementação de função temporal para exibição da data e hora atuais;
- inclusão e revisão de recursos de acessibilidade;
- organização dos arquivos do projeto em pastas.

## Observação

O projeto é executado no navegador utilizando HTML, CSS, Bootstrap e JavaScript. O formulário de cadastro e agendamento demonstra o funcionamento da interface, mas os dados não são armazenados em um banco de dados.
